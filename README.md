# Re-EL ECD

Multi-tenant SaaS platform for Early Childhood Development (ECD) centres in South Africa.

## Features

- Multi-tenant organisation management
- Role-based access control (RBAC)
- Learner management and admissions
- Curriculum planning and development tracking
- Attendance management (learners and staff)
- Parent portal
- Finance and billing
- Public websites for daycare centres
- Forms and communications
- Health and safety tracking

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript, Alpine.js, GSAP, Lucide, Chart.js
- **Backend**: Vercel Serverless Functions
- **Database**: Neon PostgreSQL
- **Hosting**: GitHub Pages (frontend), Vercel (API)

## Development

```bash
npm install
npm run dev
```
